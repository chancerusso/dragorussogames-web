# DRAGO RUSSO GAMES — FIRST EDITION MASTER INSTRUCTIONS
## (FOR CODEX + CHATGPT + ALL FUTURE WORK)

Version: 1.1  
Status: ACTIVE  
Priority: OVERRIDES PREVIOUS UX/UI ASSUMPTIONS

---

# 0. PURPOSE

Drago Russo Games First Edition exists to:

1. Teach players how to create a First Edition character.
2. Teach and explain rules.
3. Provide a readable online reference.
4. Preserve an old-school tabletop experience.

This is NOT a game application.

Success means:
A player can create a character using paper and understand the rules without external references.

---

# 1. SYSTEM IDENTITY

This project uses:

- AD&D First Edition
- OSRIC
- Drago Russo House Rules

Public explanation:

> Drago Russo Games First Edition is an OSRIC-inspired interpretation of AD&D 1st Edition with additional Drago Russo house rules.

Explain OSRIC as:

> A cleaned-up and organized presentation of classic First Edition rules.

Never present the site as:
- pure OSRIC
- modern D&D
- a VTT
- a digital character platform

---

# 2. ABSOLUTE RULE — NO CHARACTER BUILDER

DO NOT CREATE:

- Online character builders
- Stored character data
- Accounts
- Login systems
- Character persistence
- Save buttons
- Generated character sheets
- Auto calculations
- Live stat updates
- Character database
- Inventory tracking
- Session tracking
- Party management
- Campaign logs
- Digital sheets
- Character exports
- Build summaries
- Character dashboards

Character creation remains:

READ  
↓  
DECIDE  
↓  
WRITE ON PAPER

Allowed:
- Printable blank PDFs
- Fillable PDFs (future optional)
- Downloadable worksheets
- Printable Drago Russo branded sheets

Not allowed:
- Build online

---

# 3. SITE PURPOSE

This website is ONLY:

A. Step-by-step character creation guide

B. Rules reference

Nothing else.

Every new feature must answer:

"Does this teach character creation or explain rules?"

If NO:
Do not build it.
