# Drago Russo Games Work Log

This directory is the continuing operational memory for the project.

At the beginning of every coding session:

1. Read `PROGRESS.md`.
2. Read the most recent dated log.
3. Review relevant feature, architecture, and decision notes.
4. Fetch the remote repository and compare the current branch with upstream.
5. Inspect and record pre-existing worktree changes.
6. Create or update today's ISO-dated log from `TEMPLATE.md` before application
   code is changed.
7. Update the log as decisions, implementation, verification, commits, pushes,
   and deployments occur.

The log records facts and operating context, not secrets. Every unfinished item
must be carried forward. A repository push and a production deployment are
separate events and must be recorded separately.
