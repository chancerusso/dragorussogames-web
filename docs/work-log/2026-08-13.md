# Work Log — 2026-08-13

## Foundry JSON character viewer

### Objective

- Build a polished public character-sheet viewer that accepts a Foundry VTT
  Actor JSON export and automatically presents either an ARS/OSRIC or D&D 5e
  character as a compact, readable, printable sheet.
- Make the experience work well on phones while retaining the visual character
  of a sheet a player could print and bring to the table.

### Intended scope

- A new, standalone static public utility under `character-viewer/`.
- Browser-only file reading and parsing. Character JSON must not be uploaded,
  persisted to the backend, or written into the existing character vault.
- Separate visual treatments and data adapters for ARS/OSRIC and Foundry D&D
  5e/SRD 5.2 exports, behind one import experience.
- No backend, database, Drago Table, Foundry world, Foundry module, existing
  character builder, deployment, or live-service changes.

## Classic-sheet table-use refinement

### Objective and scope

- Refine only the public browser-based Character Viewer’s ARS/OSRIC sheet after

### Implementation completed

- Replaced the single numeric level seal with a compact class-level list so a
  multiclass export can show each class and its own level without collapsing
  the character into one misleading number.
- Tightened the OSRIC attack rows, kept THAC0 on one line, separated Rate from
  Range, and added support for an exported weapon attack modifier or magic
  bonus such as `+1 to hit`.
- Converted exported `1d100` proficiency targets to percentages and `1d6`
  targets to chance-on-d6 notation. Removed the redundant Base Movement entry
  and the unused Wrestle/Tackle entry from the printed check list.
- Added carried load as an Encumbrance quick statistic by totaling the
  quantities and weights actually present in the Foundry Actor export. The
  export does not contain a ready-made encumbrance category, so the viewer does
  not invent one.
- Changed player-facing classic labels from ARS/OSRIC to OSRIC while retaining
  the ARS data adapter internally.
- Added a full-width `Character Sheet · Continued` masthead to the printed
  reference page. It repeats the character name and identity before Spells,
  Coin, and Notes so page two no longer begins as an unlabelled, cut-off
  continuation.
