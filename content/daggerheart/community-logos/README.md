# Daggerheart Community Logos

These files were copied from the Darrington Press Community Content Logos package supplied by Chance.

Use these as DPCGL community/compatible logos for Daggerheart-compatible materials, subject to the Darrington Press Community Gaming License.

Working guidance:

- Prefer these community logos over official Daggerheart, Darrington Press, or Critical Role branding.
- Include required DPCGL attribution wherever Daggerheart SRD/Public Game Content is shared.
- Do not use Daggerheart name marks in the title of our work or as front-cover/main-product branding.
- Use compatibility language such as `Daggerheart Compatible` in descriptive text.
- Recheck the current DPCGL before any public release.

Source PDFs and license notes are stored in `content/daggerheart/reference/` and `docs/daggerheart-builder-vtt-notes.md`.
