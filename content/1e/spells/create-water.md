# Create Water

Create Water is an OSRIC Chapter II spell available as: Cleric 1, Druid 2.

## Spell Entries

### Cleric 1 (Reversible)

**School:** Clerical Transmutation/Alteration

| Field | OSRIC Value |
| --- | --- |
| Class/List | Cleric 1 |
| Range | 10 ft |
| Duration | Instantaneous (permanent) |
| Area of Effect | Up to 30 cubic ft |
| Components | V,S,M |
| Casting Time | 1 round |
| Saving Throw | None |

### Spell Description

This spell creates potable water, four gallons per level of the caster. The water may be created in a receptacle or in thin air (whence it will, of course, fall). Water cannot be created inside a creature, nor can it be created in any place the caster cannot see. The reverse of the spell destroys water (including fog, steam, mist, etc.) in the same quantities as create water.

### Druid 2

**School:** Druidic Transmutation/Alteration

| Field | OSRIC Value |
| --- | --- |
| Class/List | Druid 2 |
| Range | 10 ft |
| Duration | Instantaneous (permanent) |
| Area of Effect | Up to 1 cubic ft/caster level |
| Components | V,S |
| Casting Time | 1 turn |
| Saving Throw | None |

### Spell Description

Other than as described above, this spell is similar to the clerical spell create water. Note that the druidic spell has no reverse version; the druid may create, but not destroy, water.
