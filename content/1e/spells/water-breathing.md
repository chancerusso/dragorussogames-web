# Water Breathing

Water Breathing is an OSRIC Chapter II spell available as: Druid 3, Magic-User 3.

## Spell Entries

### Druid 3 (Reversible)

**School:** Druidic Transmutation/Alteration

| Field | OSRIC Value |
| --- | --- |
| Class/List | Druid 3 |
| Range | Touch |
| Duration | 6 turns/level |
| Area of Effect | One creature |
| Components | V,S,M |
| Casting Time | 5 segments |
| Saving Throw | None |

### Spell Description

This spell grants the ability to breathe underwater while the spell lasts. The reverse of the spell allows a waterbreathing creature to breathe in the air.
