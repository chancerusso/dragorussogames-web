# Detect Illusion

Detect Illusion is an OSRIC Chapter II spell available as: Illusionist 1.

## Spell Entries

### Illusionist 1

**School:** Phantasmal Divination

| Field | OSRIC Value |
| --- | --- |
| Class/List | Illusionist 1 |
| Range | Caster |
| Duration | 3 rounds + 2 rounds/level |
| Area of Effect | Path 10 ft wide, 10 ft/level long |
| Components | V,S,M |
| Casting Time | 1 segment |
| Saving Throw | None |

### Spell Description

By means of this spell, the caster sees any illusion for what it truly is. By touching an illusion, the caster can make its true form visible to any observer.
