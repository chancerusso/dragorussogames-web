# Mass Invisibility

Mass Invisibility is an OSRIC Chapter II spell available as: Magic-User 7.

## Spell Entries

### Magic-User 7

**School:** Arcane Illusion/Phantasm

| Field | OSRIC Value |
| --- | --- |
| Class/List | Magic user 7 |
| Range | 10 ft/level |
| Duration | See below |
| Area of Effect | 30 x 30 ft radius |
| Components | V,S,M |
| Casting Time | 7 segments |
| Saving Throw | None |

### Spell Description

This spell acts in the same manner as an invisibility spell, but has an effective radius of 30 x 30 ft, possibly hiding as many as 300 medium-sized creatures if they are packed in close and do not jostle one another.
