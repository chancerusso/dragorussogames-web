# Fly

Fly is an OSRIC Chapter II spell available as: Magic-User 3.

## Spell Entries

### Magic-User 3

**School:** Arcane Transmutation/Alteration

| Field | OSRIC Value |
| --- | --- |
| Class/List | Magic user 3 |
| Range | Touch |
| Duration | 6 turns/level + 1d6 turns |
| Area of Effect | One creature |
| Components | V,S,M |
| Casting Time | 3 segments |
| Saving Throw | None |

### Spell Description

This spell grants the power of flight with aerial agility level V (see Chapter III) to any creature the magic user touches. The base movement rate for flight is 120 ft per round, with the base speed being doubled when diving, halved when climbing. The referee secretly rolls a 1d6 to determine how much time the spell will last after the base duration expires.
