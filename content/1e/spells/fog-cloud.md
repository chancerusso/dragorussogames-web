# Fog Cloud

Fog Cloud is an OSRIC Chapter II spell available as: Illusionist 2.

## Spell Entries

### Illusionist 2

**School:** Phantasmal Transmutation/Alteration

| Field | OSRIC Value |
| --- | --- |
| Class/List | Illusionist 2 |
| Range | 10 ft |
| Duration | 4 rounds + 1 round/level |
| Area of Effect | 40 x 20 x 20 ft cloud |
| Components | V,S |
| Casting Time | 2 segments |
| Saving Throw | None |

### Spell Description

This spell creates a roiling mass of gas and vapour, similar in appearance to a cloudkill spell. The fog cloud moves away from the caster at 10 ft/round. Vision into the fog is limited to 2 ft.
