# Veil

Veil is an OSRIC Chapter II spell available as: Illusionist 6.

## Spell Entries

### Illusionist 6

**School:** Phantasmal Illusion

| Field | OSRIC Value |
| --- | --- |
| Class/List | Illusionist 6 |
| Range | 10 ft/level |
| Duration | 1 turn/level |
| Area of Effect | 20 x 20 ft/level |
| Components | V,S |
| Casting Time | 3 segments |
| Saving Throw | None |

### Spell Description

Veil is an extremely powerful spell of the same type as hallucinatory terrain, which alters the appearance of an area and everything in it, including people and other creatures. The illusion will fool even the sense of touch.
