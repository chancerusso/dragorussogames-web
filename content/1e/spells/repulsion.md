# Repulsion

Repulsion is an OSRIC Chapter II spell available as: Magic-User 6.

## Spell Entries

### Magic-User 6

**School:** Arcane Abjuration

| Field | OSRIC Value |
| --- | --- |
| Class/List | Magic user 6 |
| Range | 10 ft/level |
| Duration | 1 round/2 levels |
| Area of Effect | 10 ft wide path |
| Components | V,S,M |
| Casting Time | 6 segments |
| Saving Throw | None |

### Spell Description

All living creatures in the spell's path will move away from the caster at their normal movement rates for the spell's duration, as if by choice.
