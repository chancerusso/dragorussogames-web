# Grasping Hand

Grasping Hand is an OSRIC Chapter II spell available as: Magic-User 7.

## Spell Entries

### Magic-User 7

**School:** Arcane Evocation

| Field | OSRIC Value |
| --- | --- |
| Class/List | Magic user 7 |
| Range | 10 ft/level |
| Duration | 1 round/level |
| Area of Effect | Magical hand |
| Components | V,S,M |
| Casting Time | 7 segments |
| Saving Throw | None |

### Spell Description

This spell is a more powerful evocation of the forceful hand spell, acting in the same manner but able to hold motionless a creature of up to 1,000 lbs or move creatures with twice the force of a forceful hand.
