# Detect Invisibility

Detect Invisibility is an OSRIC Chapter II spell available as: Illusionist 1, Magic-User 2.

**School:** Arcane Divination

| Field | OSRIC Value |
| --- | --- |
| Class/List | Magic user 2 |
| Range | Caster |

| Area of Effect | Path 10 ft wide, 10 ft long/level |
| Components | V,S,M |
| Casting Time | 2 segments |
| Saving Throw | None |

### Spell Description

This spell allows the caster to see that which is invisible or hidden, and also to perceive the astral and aethereal planes. The spell's sight is limited to the stated range of 10 ft/caster level.
