# Monster Summoning II

Monster Summoning II is an OSRIC Chapter II spell available as: Magic-User 4.

### Spell Description

This spell functions in the same manner as monster summoning I, but calls 1d6 creatures as determined on the following table: d6 Monster Summoned 1 Centipede, giant 2 Devil, lemure 3 Gnoll 4 Stirge 5 Toad, giant 6 Troglodyte
