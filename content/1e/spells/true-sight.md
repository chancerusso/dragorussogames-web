# True Sight

True Sight is an OSRIC Chapter II spell available as: Illusionist 6.

## Spell Entries

### Illusionist 6

**School:** Phantasmal Divination

| Field | OSRIC Value |
| --- | --- |
| Class/List | Illusionist 6 |
| Range | Touch |
| Duration | 1 round/level |
| Area of Effect | 60 ft |
| Components | V,S |
| Casting Time | 3 segments |
| Saving Throw | None |

### Spell Description

This spell is identical in function (other than as may be noted above) to the clerical spell true seeing, except that the illusionist cannot discern alignments, for this spell is not of a spiritual nature.
