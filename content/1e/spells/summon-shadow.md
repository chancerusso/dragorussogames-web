# Summon Shadow

Summon Shadow is an OSRIC Chapter II spell available as: Illusionist 5.

## Spell Entries

### Illusionist 5

**School:** Phantasmal Conjuration/Summoning

| Field | OSRIC Value |
| --- | --- |
| Class/List | Illusionist 5 |
| Range | 10 ft |
| Duration | 1 round + 1 round/level |
| Area of Effect | Summoned shadows |
| Components | V,S,M |
| Casting Time | 5 segments |
| Saving Throw | None |

### Spell Description

This spell summons 1 undead shadow per caster level from the shadow planes. The shadows are under the illusionist's command and will do his or her bidding. If turned, they will return to the shadow plane whence they came.
