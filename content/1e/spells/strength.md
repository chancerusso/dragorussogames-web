# Strength

Strength is an OSRIC Chapter II spell available as: Magic-User 2.

## Spell Entries

### Magic-User 2

**School:** Arcane Transmutation/Alteration

| Field | OSRIC Value |
| --- | --- |
| Class/List | Magic user 2 |
| Range | Touch |
| Duration | 6 turns/level |
| Area of Effect | One person |
| Components | V,S,M |
| Casting Time | 1 turn |
| Saving Throw | None |

### Spell Description

This spell increases a person's strength (affecting the same sorts of creatures as hold person). The recipient's strength increases by 1d6, and members of the various fighter-type classes gain a +1 to this roll. If the spell is cast upon a monster (such as an orc), the referee is free to rule for convenience that the effect of the spell is to grant +1 to damage, and if the d6 roll is a 5 or 6, a +1 to hit as well.
